# PhishSense — Phishing Email Simulation

A controlled phishing-awareness training web application built with Flask, HTML, CSS and JavaScript.

## Included specification
- Objective: controlled phishing simulation to test awareness among peers or systems.
- Key features: realistic simulations, response tracking, vulnerability identification, prevention/training.
- Skills involved: social engineering, email security, phishing techniques.
- Learning outcomes: understand phishing methods, recognize suspicious email patterns, design preventive measures.

## Interactive simulation

After launching a scenario, the app displays a realistic simulated email. Users can click the safe training link, report the message, or ignore it. Each response produces immediate awareness feedback.

## Safety
This implementation is intentionally designed for authorized awareness training. It does not collect real passwords, authentication codes, payment details or other credentials.

## Run
1. Install Python.
2. Open a terminal in this folder.
3. `pip install flask`
4. `python app.py`
5. Open `http://127.0.0.1:5000`
